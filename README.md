# RotaNile

RotaNile is crop-rotation planning support for the Nile Delta, produced by Nile Orbit Lab.

The planner presents inputs, evidence and limits alongside any results returned by its supplied calculation engine. Until the approved browser data bundle and engine are provided, measured data and plan rankings remain unavailable; the app does not substitute sample values.

The browser and Apple icons are generated from the official Nile Orbit Lab badge supplied with the project.
